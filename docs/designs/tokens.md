## Шрифты

- **Моно:** `JetBrains Mono` — цифры, метки, логотип. Веса 200 / 300 / 400 / 500 / 600
- **Текст:** `IBM Plex Sans` — интерфейс. Веса 400 / 500 / 600
- **Serif:** `Georgia, Times New Roman` — только математика (формулы, курсивные переменные)

## Тени и свечение

### Свечение текста — активное (главные цифры)
```css
text-shadow:
  0 0 3px   rgba(255,255,255,.60),
  0 0 24px  rgba(226,232,248,.45),
  0 0 70px  rgba(186,206,240,.30),
  0 0 150px rgba(160,190,240,.20);
color: #F4F4F7;
```
Мобильная версия — те же альфы, радиусы ×0.7: `3 / 17 / 50 / 108`.

### Свечение текста — приглушённое (idle 5s)
```css
text-shadow:
  0 0 26px rgba(150,158,178,.20),
  0 0 72px rgba(150,166,196,.10);
color: #8A8A8A;
transition: color 1600ms ease, text-shadow 1600ms ease;
```

### Свечение среднего уровня (заголовочные цифры, стрик, счёт)
```css
/* 104px стрик */
0 0 3px rgba(255,255,255,.50), 0 0 22px rgba(226,232,248,.38), 0 0 64px rgba(186,206,240,.22)
```

## Обводки прогресса
- Толщина кольца: `3px` (обычное), `4px` (срочное), `2px` (splash)
- `stroke-linecap: round`
- Поворот кольца: `transform: rotate(-90deg)`
- Дорожка: `#18181D` / `#26262C`

## Анимация

| Токен | Значение |
|---|---|
| `ease-standard` | `cubic-bezier(.4, 0, .2, 1)` |
| `ease-out-soft` | `cubic-bezier(.2, .7, .2, 1)` |
| `duration-zen-dim` | `1600ms` |
| `duration-splash` | `2600ms` |
| `breathe-active` | `zenBreathe 9s ease-in-out infinite` (opacity .94 ↔ 1) |
| `breathe-dim` | `zenBreatheDim 11s ease-in-out infinite` (opacity .82 ↔ .9) |
| `idle-timeout` | `5000ms` до приглушения |

Splash (2600 ms): логотип 0→56% — `opacity 0→1`, `letter-spacing .34em→-0.03em`, `blur 10px→0`, `scale .97→1`; подпись 58%→78% — `opacity 0→1`, `translateY 8px→0`.
