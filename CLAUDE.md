# Lokked

Кросс-платформенное приложение для учёбы: таймеры по предметам + учебные карточки +
статистика. Платформы по приоритету: Linux (Fedora 43, GNOME, Wayland) → Windows →
Android → iOS.

## Стек

Tauri 2 · Rust (бэкенд) · TypeScript + React + Vite + Tailwind (фронтенд) · SQLite.
Тесты: `cargo test` (Rust), Vitest (фронтенд).

## Команды

- Разработка: `npm run tauri dev`
- Сборка: `npm run tauri build`
- Тесты: `cargo test --manifest-path src-tauri/Cargo.toml` и `npm test`
- Линтеры: `cargo clippy -- -D warnings`, `cargo fmt`, `npm run lint`

## Архитектурные правила (не нарушать)

1. **Разделение слоёв.** В `src-tauri/src/core/` запрещены импорты `tauri::`, `sqlx::`,
   `rusqlite::` и любого ввода-вывода. Это чистая библиотека: вся бизнес-логика
   (таймер, границы дня, выбор карточек, агрегации) живёт там и покрыта тестами.
   `commands.rs` — тонкий слой: распарсил аргументы, вызвал core/db, вернул результат.
   Во фронтенде бизнес-логики нет, только отображение.

2. **Время.** Длительность = `now_utc - started_at` минус паузы, вычисляется как
   чистая функция от timestamp'ов. НИКОГДА не накапливать время сложением тиков —
   приложение будет выгружаться из памяти на мобилке, и накопленное потеряется.
   Все обращения к текущему времени в `core/` идут через trait `Clock`, чтобы тесты
   использовали `FakeClock`. Прямые вызовы `Utc::now()` внутри `core/` запрещены.

3. **Схема БД — сразу под будущую синхронизацию.**
   - Первичные ключи: UUIDv7 в TEXT. Никакого AUTOINCREMENT.
   - На каждой таблице: `created_at`, `updated_at`, `deleted_at`.
   - Удаление только мягкое: `deleted_at = now`, все выборки с `WHERE deleted_at IS NULL`.
   - `sessions` и `reviews` — append-only, записи не редактируются.
   - Схема меняется только новой миграцией в `src-tauri/migrations/`. Существующие
     миграции не редактировать никогда.

4. **Данные дня НЕ удаляются в полночь.** «Сегодня» — это фильтр по `day_key`.

5. **Платформенный код.** Всё, что зависит от ОС, живёт только в
   `src-tauri/src/platform/` за trait `PlatformServices`. `#[cfg(target_os = ...)]`
   за пределами этого каталога запрещён.

6. **Адаптивность.** Каждый экран верстается mobile-first и должен корректно работать
   на ширине 380px и 1400px. Интерактивные элементы минимум 44×44px. Никаких
   взаимодействий, доступных только по hover. Проверять оба размера при каждом
   UI-изменении.

7. **Размер файлов.** Больше 400 строк — разбивать.

## Зависимости

Новые библиотеки не добавлять без явного разрешения. Разрешены: стандартные библиотеки,
Tauri и его официальные плагины, React, react-router, Tailwind, KaTeX (формулы), uuid,
chrono, rusqlite/sqlx, serde. Графики рисуем сами обычным SVG — библиотеки для чартов
не нужны.

Инструменты разработки (Vite, TypeScript, ESLint, Prettier, Vitest, Testing Library,
jsdom) в это ограничение не входят — они не попадают в собранное приложение.

## Стиль работы

- Один этап = одна ветка = один коммит с осмысленным сообщением.
- Для кода в `core/` сначала тесты, потом реализация.
- После изменений всегда прогонять тесты и `cargo clippy -- -D warnings`.
- Если требование неоднозначно — задать вопрос, а не догадываться.
- Не трогать код, не относящийся к текущей задаче.
